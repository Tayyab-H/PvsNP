# C-285 — Projection-only expander overlap has no independent synchronization rank

Date: 28 September 2026  
Classification: **ROUTE-KILL.** Scope: projection-only expander-overlap constructions.  
Route: B4, expander-overlapping local views.

## Question tested

Can an expander of overlapping local views force many different synchronization relations in a native context/proof grammar, beyond the repeated-block equality fingerprint of C-258?

The first candidate lets each local view be a restriction of the same truth table to a coordinate set `S_v subseteq [N]`, with local codebook `A_v subseteq {0,1}^{S_v}`. A selected tuple `(a_v)_v` is compatible when the view words agree wherever their coordinate sets overlap.

## Projection-collapse lemma

For any finite family `(S_v)_v`, a tuple of full local words is pairwise compatible exactly when there is one global word

```text
a in {0,1}^{S},   S = union_v S_v,
```

whose restriction to every `S_v` is `a_v`. This global word is unique. Therefore the compatible tuples from arbitrary local codebooks inject into `{0,1}^S`, and their number is at most `2^|S| <= 2^N`. For each coordinate, equality among all of its view occurrences is generated by a spanning tree on those occurrences; extra edges within that coordinate's overlap clique are redundant. Expansion does not add degrees of freedom once the coordinate-incidence classes are fixed.

At the semantic level, a consistent union of signed table literals is one partial assignment on `[N]`; repeated appearances of a coordinate collapse to its single value. If its cylinder has `f` free coordinates and is safe, then `2^f <= |SIZE(s2)|`, hence `f <= log2 |SIZE(s2)|`. This is a per-cylinder bound. It does **not** bound the number of different support descriptions or context/proof pairs that yield cylinders, which can be much larger. The conclusion is only that overlap-edge multiplicity alone does not create new table values or free coordinates.

## Why this does not prove an O(N) cover

The lemma is only about the compatibility algebra. It does not bound the rules needed to enumerate each local codebook, and it does not give a cover for all low-circuit tables. In particular, C-258's `2N+2d-1` cover uses a special product-code structure; projection collapse alone does not extend that construction to arbitrary `SIZE(s1)`.

The negative result is narrower but decisive for the proposed argument: edge expansion or a large number of pairwise overlaps, by itself, cannot be charged as many independent splice choices. Native compatibility sees signed-coordinate agreement, so an overlap graph that merely repeats the same equality constraints can be quotiented to its coordinate-incidence classes. A proof based on `|E|` or expander degree would overcount. This is not a bound on how many syntactic synchronizers a grammar can encode.

## Required hostile calibrations

- **C-80:** a common block partition admits an `O(N)` mixed-block router. The quotient lemma is compatible with this: repeated raw-coordinate structure is not a cost amplifier.
- **C-160:** the symmetric Hamming-threshold promise has an `O(N log N)` separator despite rich local recombinations. The lemma does not turn those statistics into a fusion lower bound.
- **C-228:** a random subfamily can have superpolynomial readout cost while every safe splice is an isolated anchor. The quotient lemma makes no claim that splice entropy explains every large readout lower bound.
- **C-234/C-258:** repeated-block descriptions have an explicit `O(N)` native equality fingerprint. This is the direct diagonal-equality check; the projection-overlap candidate does not exceed it.

These checks rule out interpreting projection edge density, anchor entropy, or local recombination as a global state charge.

## Refined live target

A surviving many-description construction must add coherence relations that do not reduce to equality of shared raw table coordinates. For example, local descriptions might overlap through different Boolean functions of their views. But the native support language records only signed table literals; it has no free operation that asserts a parity, gate equation, or other nonlinear relation between separate views. Any such relation must be enforced by an explicit derivation, and its rule cost must be counted. The open global theorem must therefore charge **nonprojection coherence**, not overlap density.

The useful synthesis is:

```text
projection consistency  ->  a partial assignment on at most N coordinates;
nonprojection consistency -> an explicit native-gate / proof-complexity cost is required.
```

This suggests an incidence-rank filter for future constructions: quotient repeated equalities first, then count only independent nonlinear constraints and prove that each consumes a distinct fusion resource. No such charging theorem is established here.

## Literature boundary

Austrin–Risse derive MCSP sum-of-squares lower bounds from expanding CSPs when the proof system has both suitable CSP lower bounds and a local-function substitution rule. The present native context/proof splice operation has not been shown to simulate that proof system or its substitution rule. Likewise, exponential DNNF lower bounds for expander CNFs rely on decomposable AND gates (disjoint variable scopes); C-74 intersections may overlap in table coordinates, so those theorems do not transfer without a new decomposability or overlap-charge lemma. These are technique boundaries, not claims that expansion is useless in every representation.

Sources: Austrin–Risse, [*Sum-of-Squares Lower Bounds for the Minimum Circuit Size Problem*](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CCC.2023.31); Bova–Capelli–Mengel–Slivovsky, [*A Strongly Exponential Separation of DNNFs from CNF Formulas*](https://arxiv.org/abs/1411.1995).

## Checkpoint

This kills the projection-only expander-overlap argument, not Route B. It produces no splice-partition-function lower bound, synchronization charge, near-linear full-promise cover, superlinear `q` bound, or P-vs-NP result. The actual promise bound remains `q=N-o(N)`. The qualitatively new obstruction is that overlap-edge multiplicity is not a native resource: all raw-coordinate equality constraints collapse before the closure cost is measured.
