# C-474 — balanced sketches cannot compress Low/High codebook recognition

**Date:** 1 October 2026  
**Status:** proved obstruction for a defined compression architecture. It extends coordinate-cylinder counting to arbitrary balanced sketches, including linear syndromes, but adds no new asymptotic width scale: C-230 already pins safe coordinate-cube dimension to `Theta(s2 log s2)`, and C-231 constructs a matching common safe block around every Low table. No ordinary gate lower bound improves.

## 1. Mechanism under test

Try to accelerate the C-473 proximity separator by computing a compact sketch of the `N` truth-table bits and then applying any decoder:

```text
F(T) = G(sigma(T)),
```

where `sigma:{0,1}^N -> {0,1}^q` is a deterministic balanced sketch: every nonempty fiber has size at least `2^(N-q)`. This includes any affine map of rank at most q over `F_2` and any exactly balanced q-bit sketch. The decoder `G` is unrestricted; its gates are not the limiting assumption.

The proposed compression mechanism is: all low-circuit tables land in accepted sketch fibers, while no table of complexity greater than `s2` lands in those fibers.

## 2. Theorem

Let `K2=|L_s2|`. If `F=G∘sigma` is a valid OPS separator, then

```text
q >= N - log2(K2).
```

**Proof.** Take any `T0 in L_s1`; such a table exists, for example a constant table. Since `F` is valid, `G(sigma(T0))=1`. The fiber `A=sigma^(-1)(sigma(T0))` contains at least `2^(N-q)` strings. If `q<N-log2(K2)`, then `|A|>K2`, so A contains some table `T1` outside `L_s2`. This T1 is a promised NO input, but

```text
F(T1) = G(sigma(T1)) = G(sigma(T0)) = 1,
```

contradicting soundness. Therefore `q>=N-log2(K2)`. This proof permits an arbitrary, even unbounded-size, decoder G.

For ordinary fan-in-two circuits, description counting gives

```text
log2(K2) = O(s2 log(n+s2)) = O(N^beta n) = o(N)
```

for fixed `0<beta<1`. Thus a balanced sketch separator must retain at least `N-O(N^beta log N)` bits of sketch width. In particular, no syndrome with `q=o(N)` can be the complete information bottleneck for a valid separator.

## 3. Strongest counterconstruction and calibration

This is a counting construction of a collision, not an explicit table generator. For each accepted Low table and each balanced sketch fiber containing it, the fiber is larger than the entire size-`s2` codebook whenever `q<N-log |L_s2|`; hence at least one member of that very fiber is High. The argument is stronger than choosing a random completion of a coordinate cylinder because the sketch can be any balanced nonlinear map, not just a set of raw coordinate reads.

The anchor `T0` can be chosen from each of the requested hostile families, with explicit Low budgets for sufficiently large N:

- parity has `O(n)` gates;
- a table constant on `k=c*s1` address blocks has an address decoder and `k`-bit mux of `O(n+k)` gates, hence is Low for small fixed c;
- a conjunction of `O(n)` parity checks, each on at most n address bits, costs `O(n^2)` gates and is Low;
- a repeated-block relation generated by a simple `O(k+n)` circuit is Low for the same choice `k=c*s1`.

For any of these anchors, its accepted sketch fiber contains a High table whenever `q<N-log|L_s2|`. The High collision is nonconstructive, but enough to refute soundness of the proposed sketch architecture. These examples do not refute an arbitrary separator lower bound.

## 4. C-230/C-231 already saturate the safe-fiber width scale

[C-230](C230_HIGH_FREE_SUBCUBE_DIMENSION_CALIBRATION_2026-09-27.md) proves

```text
kappa_square(s2) = Theta(s2 log s2) = Theta(log |L_s2|)
```

up to fixed-beta constants. [C-231](C231_LOW_FIBER_ROBUSTNESS_AND_UNIVERSAL_PROJECTION_2026-09-27.md) constructs one fixed prefix block `B` of `m=Theta(s2 log s2)` truth-table coordinates such that changing the contents of B arbitrarily around **any** Low anchor still gives a table in `L_s2`.

Delete B with the coordinate projection `pi`. This is a balanced sketch of width `q=N-m=N-Theta(s2 log s2)`. C-426 already packages this into a complete separator and accounts for its gates, wires, description bits, and construction time. Define

```text
G(y)=1 iff y in pi(L_s1).
```

This gives a valid separator: all Low tables pass; a High table cannot share its projection with a Low table, since it would then be one of the safe completions on B. Enumerating the projected Low codebook still costs `O(N*2^(O(N^beta)))` gates. Thus C-230/C-231/C-426 already achieve a valid balanced sketch at the counting lower-bound width scale, but they do not compress its decoder. C-474's addition is the necessity proof for arbitrary balanced sketches, not a new order-of-magnitude geometric threshold or an untested construction direction.

This identifies the remaining projection barrier. To project an **arbitrary** separator F through this safe block, C-231 forms `g(p)=AND_u F(p,u)`. Direct expansion costs `2^m` cofactors, and universal quantification fails to commute with the predecessor ORs in the existing proof grammar. [C-427](C427_ROBUST_FIBER_AND_GATE_ELIMINATION_AUDIT_2026-09-30.md) shows that a generic polynomial-overhead compiler for arbitrary circuit universal quantification would have coNP/poly collapse consequences. A useful compiler must exploit a proved promise-specific structure of F; it cannot assume every separator factors through `pi`.

## 5. Scope and exact limitation

- This rules out **balanced-sketch-then-decode** separators with sketch width below `N-O(N^beta log N)`. It includes affine/linear syndrome and hash sketches.
- It does **not** bound the total gates needed to compute a sketch of width near N. A width lower bound is not a superlinear gate lower bound.
- It does **not** apply to an arbitrary separator. Its internal state need not factor through a balanced sketch; a general Boolean circuit can retain highly nonuniform, nonlinear information.
- It does **not** prove that the C-473 proximity predicate is hard or easy. It shows that a generic short balanced fingerprint cannot compress the candidate search.
- It is not an independent barrier to all fibers/search-to-decision approaches; it is a completed route filter, closely related in proof spirit to cylinder counting, now for balanced sketches.

**Adjacent sharing-literature check.** Krinkin's 2026 preprint *The Unit Gap: How Sharing Works in Boolean Circuits* is explicitly marked withdrawn; the arXiv notice gives three-bit parity as a counterexample to its central formula-versus-circuit gap claim. The paper's AIG model also has free inversions, unlike the project's total-gate measure. It supplies no sharing theorem for this project. [Primary notice and counterexample](https://arxiv.org/abs/2603.08033).

## 6. Effect on the project

No frontier change. The ordinary lower bound stays `N-O(N^beta log N)` with C-406's refinement; the complete enumerative upper stays `O(N*2^(O(N^beta)))`. OPS's common-fixed-epsilon target, the native `rho` target, and P-vs-NP remain open.

**Next consequence:** close low-width sketching and generic safe-block projection as current routes. C-230/C-231/C-426 already give the coordinate projection and exact enumerative decoder, while C-427 retires generic universal-quantifier compilation. Reopen this branch only with a concrete shared-decoder construction or a new promise-specific gate identity; do not restate “compress projected membership.” The direct lower-bound branch still needs an operation-wise charge for arbitrary shared DAGs.
