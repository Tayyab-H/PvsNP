# C-429 — Gate-transcript fibers are 2-CNF, but do not charge post-read work

**Status:** exact structural lemma for ordinary fan-in-two DAGs; its strongest direct consequence is only linear. A padded identity front end makes the decisive failure explicit. No quantitative frontier change.

## 1. Target and model

Write `N=2^n`. Use the OPS promise

```text
YES: CC(f) <= s1 = N^beta/(10n)
NO:  CC(f) >  s2 = N^beta
```

with behavior unrestricted between the thresholds. The theorem asks for one fixed `epsilon>0` such that every sufficiently small fixed `beta>0` requires more than `N^(1+epsilon)` total gates in an ordinary fan-in-two circuit. OPS states the universal-constant version `s1=N^beta/(c n)` and proves the magnification implication with one epsilon for all sufficiently small beta; its conclusion is `NP not-subset P/poly`. The constants and quantifiers were checked against Theorem 1.4 and Definition 2.4 of the published paper.

Circuits below are acyclic, have unrestricted fan-out, and count every Boolean gate. Wires, gate-list bits, construction time, and native fusion states are separate measures.

## 2. Candidate mechanism: the 2-CNF structure of a complete gate transcript

Let `C` be any fan-in-two circuit with `S` gates and `N` primary inputs. For a bit string `tau` giving the value of every gate, define its transcript fiber

```text
F_tau = { x in {0,1}^N : every gate of C evaluates to its tau-value on x }.
```

### Lemma 1 — Every transcript fiber is a 2-CNF solution set

For every `tau`, `F_tau` is either empty or exactly the set of satisfying assignments of a 2-CNF formula with at most `4S` clauses.

**Proof.** Fix all internal gate values to `tau`. For each gate, its output is fixed and each input wire is now either a primary variable, a constant, or a previously fixed gate value. If both inputs are primary variables, the gate's fixed-output relation is an arbitrary subset of `{0,1}^2`; forbid each disallowed pair with one 2-literal clause, requiring at most four clauses. If one input is a primary variable, the allowed values of that variable are expressible with at most two unit clauses. If neither is primary, the condition is either automatically true or makes the fiber empty. Conjoining these local constraints gives at most four clauses per gate. Conversely, any primary assignment satisfying the constraints realizes `tau`, by induction in topological gate order. ∎

The argument holds for any fan-in-two Boolean basis, not only AND/OR/NOT. A satisfying set of a 2-CNF formula is closed under coordinatewise majority: if a majority assignment falsified a clause, at least two of the three source assignments would falsify each of its at most two literals, and those two index sets intersect, contradicting that all three source assignments satisfy the clause.

### Lemma 2 — Accepted fibers contain no High tables

If the output-gate bit of `tau` is 1 and `C` is a valid OPS separator, then `F_tau subseteq SIZE(s2)`. Every High table is rejected, so every input in this fiber has circuit complexity at most `s2`.

The Low set is covered by the accepting transcript fibers. Thus each accepting fiber is a majority-closed set contained in `SIZE(s2)`, and the full accepting cover is generated by a common library of at most `8S` possible clauses (each gate can contribute at most four clauses for either fixed output value).

## 3. Proof attempt: what this mechanism actually charges

The transcript lemma gives a valid but weak gate lower bound. An accepting fiber is nonempty because the all-zero truth table is Low. Although the formula has at most `4S` clauses, a sharper count is that each gate has at most two primary-input pins, so the whole fiber formula mentions at most `2S` distinct primary variables. Every unmentioned variable is free throughout the fiber. Consequently the fiber contains a subcube of size at least `2^(N-2S)` (when `2S<=N`).

Circuit counting on the `n`-input truth tables gives

```text
|SIZE(s2)| <= 2^(O(s2 log(s2+n))) = 2^(O(N^beta n)).
```

Since an accepting fiber is contained in `SIZE(s2)`,

```text
2^(N-2S) <= 2^(O(N^beta n)),
S >= (N-O(N^beta n))/2.
```

This is a gate potential with an operation-wise cap: for a fixed accepting transcript, `Phi_tau = |var(F_tau)|` satisfies `Phi_tau<=2S`. In a topological gate-construction sequence, appending one fan-in-two gate can introduce at most two raw input variables into the transcript constraints; reusing an earlier gate output as a new gate input does not multiply this charge. Soundness forces `Phi_tau>=N-O(N^beta n)`, because otherwise its fiber would contain too many truth tables. This is a genuine consequence of transcript semantics with arbitrary sharing, but it is weaker than the established `N-O(N^beta n)` essential-input bound up to constants and has no superlinear output value. It does not charge any gate after the input has been exposed.

The majority closure gives a second exact constraint: three Low tables in one accepting fiber have a Low-or-middle coordinatewise majority. This creates no immediate amplifier. A majority of three `s1`-size functions itself has size at most `3s1+O(1)<s2`, so the first closure step is automatically non-High.

## 4. Strongest counterconstruction to the mechanism

### Identity front end hides an arbitrary post-read decoder

Add `O(N)` copy gates `u_i=x_i` (for example, `u_i=x_i AND x_i` in the usual gate convention) and feed them to any later decoder circuit `D(u_1,...,u_N)`. The total circuit has `O(N)+|D|` gates. Fixing the full transcript fixes every `u_i`, so every nonempty transcript fiber is a singleton, described by `N` unit clauses. All the later decoder gates are determined by those input values and do not further restrict the fiber. Therefore every transcript-fiber or majority-closure statistic is already maximally resolved after `O(N)` gates, while the post-read computation can still be arbitrarily large.

For the GapMCSP target, `D` would itself be the desired separator; this padding is not an upper bound on `D`. It is a counterexample to using transcript geometry alone to charge the extra gates that `D` uses after all input bits are known.

### A large safe fiber from sparse patches

Choose a coordinate set `B` of size `r=floor(s1/(10n))` among the `N` input table bits. Let `C_B` output `AND_{i notin B} (NOT x_i)`, using `O(N)` ordinary gates. On the transcript realized by inputs that are zero outside `B`, the fiber is exactly

```text
F = {x : x_i=0 for i notin B},   |F|=2^r.
```

Every member is the truth table of a function with at most `r` ones, hence has a minterm DNF of size `O(rn+n) <= s1` for sufficiently large `N`. This is an actual large accepting transcript fiber in the AND/OR/NOT model. It contains many Low tables and no High table, although `C_B` is only a subpromise predicate and is not a full GapMCSP separator.

Repeated-block equality gives a related but distinct check. The set of tables depending only on a fixed `k`-bit address prefix is a 2-CNF set with `O(N)` coordinate-equality clauses, and for `k=floor(beta*n-3*log2(n))` all its `2^(2^k)` members are Low by the direct minterm-DNF bound. This refutes any argument using only the shape and safety of arbitrary 2-CNF sets. In the AND/OR/NOT basis we do not claim this whole repeated-block set is one complete gate-transcript fiber; internal comparator wires may split it into multiple fibers.

These constructions show why neither “each Low input needs its own transcript” nor “safe fibers must be small” is available. A common O(N)-gate readout can encode all input bits, and a single transcript can already contain exponentially many Low sparse patches.

## 5. Requested shared-computation calibrations

| Input predicate used as a calibration | Shared fan-in-two implementation | What it rules out |
|---|---:|---|
| Parity of all `N` bits | `O(N)` gates; replace each XOR by a constant-size AND/OR/NOT gadget | Full support or total influence as a superlinear charge |
| Equality of repeated blocks | `O(N)` comparisons and an AND tree | Per-copy or per-incidence charges |
| `m` sparse parity checks with `I=O(N)` incidences | `O(I+m)=O(N)` gates | Per-check or per-incidence charges |
| Copy/complement or a fixed simple relation among blocks | Compute the shared rule once and verify the `N` positions in `O(N+R)` gates | Charging expanded dependencies instead of shared gates |

These are not GapMCSP separators. They refute generic extrapolations from transcript width, relation count, or readout multiplicity to total gates.

## 6. Paired full-promise separator attempt

The transcript route did not produce a faster full-promise circuit. The unconditional exact construction enumerates the `K=2^(O(s1 log(s1+n)))=2^(O(N^beta))` descriptions of Low circuits, compares the input table against each candidate at all `N` coordinates, then ORs the equality flags:

```text
total gates:       O(NK) = O(N*2^(O(N^beta)))
wires:             O(NK)
gate-list bits:    O(NK log(NK))
construction time: separate from gate count
```

It accepts every promised YES and rejects every promised NO; the middle band is immaterial. The quotient/fiber analysis does not reduce the candidate count or the per-candidate comparison cost.

There is a published near-linear full-promise separator *conditionally* under `NP subseteq P/poly`: the OPS anti-checker construction supplies `t=N^(10 beta)` addresses, then a Succinct-MCSP verifier checks whether one size-`s1` circuit matches all listed labels. In total-gate terms, OPS bounds the selector by `N^(1+k beta)` for a constant `k`, the address formatter and table lookups by `O(tN)=O(N^(1+10 beta))`, and the assumed verifier by `m^ell` for `m=N^(10 beta) poly(n)` and fixed `ell`. Choosing beta sufficiently small makes their sum `N^(1+epsilon)` for the theorem's fixed epsilon. The selector/verifier construction is where `NP subseteq P/poly` is used. This is not an unconditional upper bound or a new construction. No unconditional `N^(1+o(1))` separator was found in this cycle.

## 7. Model, barrier, and originality audit

- **Total gates:** all bounds above count fan-in-two Boolean gates. No AND-only count is substituted.
- **OR, wires, descriptions, runtime:** OR gates are charged as gates; free fan-out does not create gate cost. Wire count, description bits, and constructing the circuit are not counted as total gates.
- **Native fusion:** no `q^2` paid-AND unrolling is treated as a total-gate compiler. This report makes no native `rho` claim and does not transfer a DAG transcript argument to cyclic closure. Arbitrary semantic endpoints, wide seeds, reuse, cycles, and every required semi-filter extension remain outside this proof.
- **Magnification:** OPS Theorem 1.4 uses one fixed `epsilon>0` for every sufficiently small fixed `beta>0`, with low threshold `N^beta/(c n)` and high threshold `N^beta`. The consequence is `NP not-subset P/poly`; the theorem is not itself a lower-bound proof.
- **Known barriers:** Chen et al.'s locality barrier concerns specified lower-bound techniques and local-oracle frontiers. It is not a universal impossibility theorem for global DAG lower bounds. The transcript lemma neither bypasses nor strengthens it.
- **Originality:** Lemma 1 is an elementary local-constraint observation, and 2-CNF majority closure is standard. The report records their exact application and failure on the OPS target; it claims no new general circuit-lower-bound technique.

## 8. Outcome and mechanism change

**Strongest proved statement this cycle:** each complete transcript fiber of a fan-in-two DAG is a 2-CNF set; every accepting fiber is contained in `SIZE(s2)`; its distinct-variable potential yields `S >= (N-O(N^beta n))/2`. The existing stronger linear frontier remains in force.

**Decisive obstruction:** the fiber depends on which primary-input constraints are fixed, but gates that compute from an already exposed input transcript do not further restrict any fiber. An `O(N)`-gate identity front end can make every fiber a singleton before the unknown decoder does its work; conversely, a valid accepting fiber can contain `2^r` sparse Low patches. This mechanism therefore cannot explain a superlinear post-read cost.

Retire transcript-fiber volume, majority closure, and safe-fiber cardinality as standalone superlinear routes. The next ordinary-circuit attempt must directly constrain the post-read Boolean decoder for the full promise, or give a promise-preserving hard trace with the complete map cost included. This is a requirement on the proof, not an assumed non-shareability principle.

**Quantitative frontier: unchanged.** Ordinary lower bound remains `N-O(N^beta log N)-1` plus C-406's additive logarithmic refinement; the OPS `N^(1+epsilon)` target is open. Exact unconditional full-promise upper remains `O(N*2^(O(N^beta)))`. Native `rho_GapMCSP>=N-o(N)` remains separate.
