# C-236 — Disagreement-restricted selector cap for compatible splices

Date: 27 September 2026  
Scope: sharpen C-235's endpoint target on the C-234 repeated-anchor family. A compatible splice between two repeated low tables induces a Boolean ownership selector on their disagreement coordinates. The selector is computable from the low endpoint and the two anchors, so soundness allows only a tiny fraction of all selectors. This is a profile cap, not a q lower bound.

## 1. Setup

Let $N=2^n$, fix $0<\beta<1$, and take OPS scales $s_2=N^\beta$, $s_1=s_2/(c n)$. As in C-234, choose k so $m=2^k=\Theta(s_2)$ and every k-input Boolean function has circuit size at most $s_1/4$. Put $r=N/m$, split an address as $(p,u)\in\{0,1\}^{n-k}\times\{0,1\}^k$, and repeat each k-bit function across the r prefix blocks:

    w_g(p,u)=g(u).

Fix two such anchors $w_g,w_h\in\mathrm{SIZE}(s_1)$. Their disagreement set is

    D(g,h)={(p,u):g(u)\ne h(u)}.

For independent uniform g,h, the suffix disagreement count is Binomial$(m,1/2)$, so with probability $1-e^{-\Omega(m)}$, $|D(g,h)|\ge N/3$.

## 2. Selector-extraction lemma

Let K be the outside-context support from an accepting proof of $w_g$, and let C be a finite replacement support rooted at the same state, selected from an accepting proof of $w_h$. Thus $K\subseteq\Lambda(w_g)$ and $C\subseteq\Lambda(w_h)$. Assume $K\cup C$ is consistent. Let

    z_minus=ell(K union C),   z_plus=u(K union C)

be its two canonical endpoints. By C-235 and soundness, both are in SIZE(s2).

On each coordinate in $D(g,h)$, each endpoint chooses one of the two anchor values. If a side pins that coordinate, consistency forces its pinned value to agree with that side's anchor. If neither side pins it, $z_-$ sets it to 0 and $z_+$ sets it to 1, which again agrees with one of the two differing anchor bits. Let $d=w_g\oplus w_h$, and define the disagreement-restricted selectors

\mu_- = d\land(z_-\oplus w_h),
\mu_+ = d\land(z_+\oplus w_h).

On $D$, $\mu$ is 1 exactly where the endpoint chose g and 0 where it chose h; outside $D$ it is 0. Each selector is a circuit of size at most

    CC(w_g)+CC(w_h)+CC(z_*)+O(1) <= s_2+2s_1+O(1).

There is also a useful completion hidden in this selector. Define

    H_mu = w_h XOR mu.

This table extends the mixed support $K\cup C$: on $D$, it follows the endpoint's selected anchor, and outside $D$ the two anchors agree with every rail in K or C. Hence $H_\mu\in Q(K\cup C)\subseteq\mathrm{SIZE}(s_2)$. The same argument applies to both $\mu_-$ and $\mu_+$. It follows additionally that $CC(\mu)\le s_2+s_1+O(1)$, since $\mu=H_\mu\oplus w_h$.

For fixed g,h, define

    L_{g,h}={mu subset D : H_mu is in SIZE(s2)}.

The map $\mu\mapsto H_\mu$ is injective, so $|L_{g,h}|\le|\mathrm{SIZE}(s_2)|$. Every selector induced by a compatible splice belongs to $L_{g,h}$. Thus

|{mu_minus arising from compatible proof splices}| <= |SIZE(s2)|,
|{mu_plus arising from compatible proof splices}|  <= |SIZE(s2)|.

This cap applies across all states, all selected proof contexts for g, and all replacement proofs for h. It is a direct, exact constraint on the image of the context-by-subproof product.

## 3. Most ownership masks are forbidden

For a typical independent pair $g,h$, $|D|\ge N/3$, so there are $2^{|D|}\ge2^{N/3}$ possible ownership masks. Circuit counting gives

    |SIZE(s2)| <= 2^{O(s2 log(s2+n))}=2^{O(N^\beta n)}=2^{o(N)}

for every fixed $\beta<1$. Consequently, at most a $2^{-\Omega(N)}$ fraction of all disagreement masks can occur as a canonical endpoint selector of a compatible splice. Every mask outside $L_{g,h}$ has a high canonical hybrid $H_\mu$ by definition, so no compatible splice can induce it.

This is sharper than just saying most unrestricted hybrids are high: it identifies the exact obstruction at the reuse interface. Any successful grammar must restrict compatible context/replacement products so their disagreement-selector image lies in a set of at most (|\mathrm{SIZE}(s_2)|) masks.

## 4. Hostile check and what remains

The C-234 diagonal equality cover explains how this cap can hold cheaply on a restricted subpromise. Its accepting set is exactly the repeated-block class. A nonempty accepting interval must therefore be a singleton diagonal table; any compatible endpoint selector between (w_g,w_h) depends only on u, not on p. The profile is confined to at most (2^m=2^{\Theta(s_2)}) prefix-constant masks, safely below the (2^{O(s_2 n)}) circuit-count cap. The cover uses O(N) rules, so the cap alone cannot prove superlinearity.

The missing theorem is now concrete:

> For a q-state grammar accepting every table in SIZE(s1), bound the number/structure of disagreement-selector masks generated by its full context/subproof products. Show that keeping this image inside SIZE(s2) for every low-anchor pair costs q>=N^(1+epsilon) for some fixed epsilon>0 (or first prove q=N g(N) for an unbounded g), or construct a near-linear grammar that does so.

A raw count of proof trees is not enough: a q-state cyclic grammar can have many finite unfoldings, and seed incidence sets are unbounded in the rule-count measure. The needed charge must exploit how a shared q-state grammar generates the compatible mask families across many pairs g,h. C-80/C-121/C-134/C-160/C-161/C-213, C-228, and C-230 remain hostile tests.

**Status:** selector extraction and the (2^{o(N)})-versus-(2^{\Omega(N)}) profile cap are proved. No bound on q follows, because no theorem yet forces the context/subproof grammar to realize more than the allowed masks. No full-promise superlinear fusion bound, near-linear full-promise cover, or P-vs-NP proof follows.
